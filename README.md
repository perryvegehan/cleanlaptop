# CleanLaptop

## Setup

Clone the repository:

```bash
git clone https://github.com/perryvegehan/cleanlaptop.git
cd cleanlaptop
```

Run the setup command:

```bash
./setup.sh
```

This automatically:
- Creates a Python virtual environment.
- Installs required dependencies.
- Installs the Git pre-commit hook.
- Executes the Python script once during setup.

After installation, the Python script will also execute automatically before every Git commit.
